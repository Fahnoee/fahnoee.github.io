## About

This project is my personal portfolio, built to showcase my skills and projects. It is created using modern web technologies and deployed on GitHub Pages.

## Technologies Used

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- tsParticles

## Setup and Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-github-username>/<your-repo-name>.git
   ```
   *(Please replace `<your-github-username>` and `<your-repo-name>` with your actual GitHub username and repository name.)*

2. **Navigate to the project directory:**
   ```bash
   cd <your-repo-name>
   ```

3. **Install NPM packages:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   This will start the application locally, usually at `http://localhost:5173`.

## Deployment

This project is configured for easy deployment to GitHub Pages.

1. **Ensure your repository is correctly set up on GitHub.**
2. **Run the deploy script:**
   ```bash
   npm run deploy
   ```
   This script will build the project and push the contents of the `dist` folder to the `gh-pages` branch, which will then be served by GitHub Pages.
